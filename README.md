# 分娩の地理 — Birth Atlas

全国の病院・有床診療所の分娩公表値を、3D地図と年次再生で探索する静的Webサイトです。

公開先：**https://mattyamonaca.github.io/JP_Birth_Vis/**（初回デプロイ成功後に閲覧できます）

## できること

- 施設の位置に立つ棒で、選択年の分娩件数を表示
- 年スライダー・再生／一時停止による推移の確認
- 都道府県・施設種別での絞り込み、施設名の検索
- 施設別推移、地域の公表値合計、同一施設での前年比・初年比較
- モバイル表示と、WebGLが使えない環境での2D代替表示

地図上の棒または施設検索結果を選ぶと、施設の数値と推移を確認できます。棒の高さは年間が1件あたり80m相当、単月が800m相当という表示上の固定倍率です。実際の建物の高さではありません。

## データの範囲と注意点

| 項目 | 内容 |
| --- | --- |
| 年間値 | 2020〜2024年度（各4月〜翌3月、2021〜2025年報告） |
| 旧年の単月値 | 2016〜2020年の各6月の1か月分 |
| 分娩の定義 | 正常分娩・帝王切開を含み、死産を除く |
| 集計方法 | 病院は病棟の公表値を合算、有床診療所は施設の公表値 |
| 対象 | 分娩実績または秘匿等の記録がある2,706施設。全医療機関の名簿ではない |
| 対象外 | 助産所、無床診療所、未掲載施設 |
| 座標 | 医療情報ネットの2026年6月1日時点の公表座標。2,167施設に対応、539施設は未取得 |
| 数値取得日 | 2026年10月16日 |

年間と6月単月は別の系列です。単月を12倍して年換算したり、両者を接続したりしません。旧単月には大きな原報告異常があり、品質フラグを除外しても実態変化の判断には検証が必要です。

秘匿・未報告はゼロに置き換えず、棒・合計・増減比較から除外します。同じ正値が複数病棟にある値や、確認用閾値（年間5,000件・単月500件）を超える値には「原報告要確認」を付け、初期状態では除外しています。これは誤りを断定する判定ではありません。要確認値を含める操作でも原値は補正しません。

前年比・初年比較は、両年に数値があり同じ品質条件を満たす**同一施設集合**で計算します。当年合計の対象施設とは異なる場合があります。合計は掲載施設の公表値であり、全国・地域の出生総数ではありません。座標未取得でも数値条件を満たす施設は地域集計に含めます。

過去の値も最新の公表座標へ表示しており、移転前の位置は追跡していません。地域も対応できた最新の自治体情報を用います。曖昧な名称対応は座標未取得のままとし、都道府県の中心などへ仮配置しません。施設種別と報告コードで年をつないでおり、コード変更・統廃合・病院と診療所の転換の追加名寄せは行っていません。

## 出典・ライブラリ

- [厚生労働省・病床機能報告](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000055891.html)：分娩公表値。年ごとの原資料URLは `data/facilities.json` の `meta.sources` に収録。
- [厚生労働省・医療情報ネットのオープンデータ](https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/kenkou_iryou/iryou/newpage_43373.html)：施設座標・住所。
- [国土地理院・地理院タイル](https://maps.gsi.go.jp/development/ichiran.html)：淡色地図。閲覧時に国土地理院から配信。
- [Natural Earth](https://www.naturalearthdata.com/)：1:50mの日本概略境界。配布元は [natural-earth-vector](https://github.com/nvkelso/natural-earth-vector)。パブリックドメイン。
- [MapLibre GL JS](https://github.com/maplibre/maplibre-gl-js/tree/v5.6.0)：5.6.0をローカル同梱。ライセンス全文は `assets/maplibre-LICENSE.txt`。

背景は国土地理院の淡色地図です。初期表示・「全国へ」・都道府県の選択解除では北海道〜沖縄・先島諸島を含む日本全域を画面に合わせ、移動範囲は日本周辺に制限します。周辺国の一部も表示されます。

アプリ・ライブラリ・境界・数値データは同一サイトから読み込みます。JavaScript/CSSのCDNや外部Webフォントに依存しません。背景タイルには外部通信が必要ですが、取得できない場合も同梱境界と施設表示を利用できます。

## ローカル確認

ビルドやパッケージのインストールは不要です。リポジトリ直下で起動します。

```sh
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000/` を開きます。ファイルを直接開く `file://` 形式は、JSON取得やJavaScriptモジュールの制限があるため使用しません。

検証にはNode.jsとPython 3を使います。

```sh
node --check app.mjs
node --check core.mjs
node scripts/check-core.mjs
python3 scripts/check-static.py
```

## GitHub Pages

リポジトリの **Settings → Pages → Source** を **GitHub Actions** に設定します。`main` へのpush、またはActionsの手動実行で検証・公開します。

`.github/workflows/pages.yml` はGitHub公式のPages Actionsを使用し、公開対象のファイルだけを `_site/` にまとめて配信します。README・検証スクリプト・Git情報は配信物に含めません。

すべてのアプリ参照は相対パスで、`/JP_Birth_Vis/` のプロジェクトサイトに対応します。MapLibreのworkerは同梱スクリプトからBlobとして生成され、別ホストのworkerやルート絶対パスを要求しません。
